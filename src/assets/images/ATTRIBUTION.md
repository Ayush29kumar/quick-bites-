# Image attribution

The food and restaurant illustrations in this folder are Noto Emoji artwork by Google
(https://github.com/googlefonts/noto-emoji), distributed through the `@svgmoji/noto`
npm package (https://github.com/svgmoji/svgmoji). The artwork is licensed under the
Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0).

File names are the Unicode code points of each emoji (for example `1F355.svg` is the pizza).
